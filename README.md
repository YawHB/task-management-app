# Task Management Application
## A modular Monolith Built with Java and Spring Boot

A task management application built with Java, Spring Boot, and PostgreSQL. 
The application uses a modular monolith architecture with clearly defined module boundaries, 
a design-first REST API specified with OpenAPI, and database migrations managed through Flyway. 
Each module encapsulates its own business logic and data access, communicating with other modules through public Facades. 
The project also incorporates a centralised exception handling, and cross-module validation
to support a maintainable and well-structured backend.
